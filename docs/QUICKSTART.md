# Quick Start

1. Upload the `public/` folder to your hosting provider, or connect this repository to Netlify.
2. Confirm that `public/index.html` opens correctly.
3. For local use, run `npm install` followed by `npm start`.
4. For Supabase-backed features, apply `database/supabase-schema.sql` first.

Important paths:

- `public/index.html`: main page
- `public/pages/`: internal pages and admin dashboard
- `public/assets/css/style.css`: styles
- `public/assets/js/main.js`: site behavior
- `public/assets/images/`: images
- `public/assets/logos/`: software logos
